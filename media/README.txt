PANEL DE SONIDOS
=================

1. Copia aquí tus archivos de audio.
   Formatos recomendados: .ogg, .mp3 y .wav.

2. Edita sonidos.json y añade una entrada por botón:

[
  {
    "id": "airhorn",
    "nombre": "Air Horn",
    "archivo": "airhorn.ogg",
    "emoji": "📢"
  },
  {
    "id": "bruh",
    "nombre": "Bruh",
    "archivo": "bruh.mp3",
    "emoji": "💀"
  }
]

El campo archivo es relativo a esta carpeta media/.
Después pulsa “Recargar sonidos” en la web o refresca la página.
